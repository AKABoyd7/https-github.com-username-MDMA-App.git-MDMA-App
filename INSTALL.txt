วิธีติดตั้งและใช้งาน MDMA AI Agent (ภาษาไทย)
===========================================

ขั้นตอนที่ 1: ติดตั้ง Python
---------------------------
1. ดาวน์โหลด Python จาก https://www.python.org/
2. ติดตั้ง โดยเลือก "Add Python to PATH" ด้วย
3. เปิด Command Prompt แล้วพิมพ์ python --version เพื่อเช็ค


ขั้นตอนที่ 2: ติดตั้ง Ollama
---------------------------
1. ดาวน์โหลด Ollama จาก https://ollama.ai
2. ติดตั้งตามปกติ
3. เปิด Command Prompt แล้วพิมพ์:
   ollama pull llama3
4. รอดาวน์โหลดโมเดล (ประมาณ 4GB)


ขั้นตอนที่ 3: โคลนหรือคัดลอกโปรเจกต์
---------------------------
วิธีที่ 1: ถ้ามี Git URL
git clone [URL]
cd MDMA-App

วิธีที่ 2: คัดลอกไฟล์ทั้งหมด
สร้างโฟลเดอร์ใหม่ แล้วคัดลอกไฟล์ทั้งหมดเข้าไป


ขั้นตอนที่ 4: รันโปรแกรม
---------------------------
วิธีที่ 1 (ง่ายที่สุด):
- ดับเบิลคลิก START.bat

วิธีที่ 2 (Manual):
1. เปิด Command Prompt ในโฟลเดอร์โปรเจกต์
2. พิมพ์: pip install -r requirements.txt
3. พิมพ์: python agent.py


การใช้งาน
---------------------------
1. พิมพ์ข้อความ แล้วกด Enter
2. AI จะตอบกลับ
3. พิมพ์ "exit" หรือ "quit" เพื่อออก


แก้ปัญหา
---------------------------
❌ ถ้าขึ้น "Ollama connection failed":
   - เปิด Command Prompt ใหม่ แล้วพิมพ์: ollama serve
   - ปล่อยหน้าต่างนั้นทิ้งไว้
   - เปิด Command Prompt ใหม่มารันโปรแกรมอีกครั้ง

❌ ถ้าขึ้น "Module not found":
   - พิมพ์: pip install langchain langgraph langchain-community

❌ ถ้าขึ้น "Python not found":
   - ติดตั้ง Python ใหม่ โดยเลือก "Add to PATH"
